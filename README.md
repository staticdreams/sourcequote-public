# SourceQuote (public)

SourceQuote is a native macOS GitHub client with built-in agents and an MCP server. This repository is its public side:

- **Downloads:** signed, notarized DMGs on the [Releases](../../releases) page.
- **Updates:** the Sparkle feed the app checks, [`appcast.xml`](appcast.xml), served at
  `https://staticdreams.github.io/sourcequote-public/appcast.xml`.
- **A playground:** issues, pull requests and discussions here are used to test the app against real GitHub. Expect
  throwaway content.

The source code is private.
